# Misis' Shopping Tracker v2.0

Offline, pang-mobile. Lahat ng data ay nasa phone mo lang (hindi napupunta sa GitHub).

## I-upload sa GitHub Pages
1. Gumawa ng repo, i-upload ang LAHAT ng laman ng folder na ito (index.html, sw.js, manifest.json, css, js, json, assets).
2. Settings → Pages → Branch: main, folder: / (root) → Save.
3. Buksan ang link sa Chrome ng phone → ⋮ → "Install app" / "Add to Home screen".
4. Pagkatapos ng unang bukas, gagana na ito offline. Kapag online, kusa itong kumukuha ng bagong version.

## Mag-update
I-upload lang ulit ang binagong files sa repo. Sa susunod na bukas mo online, ito na ang gamit.

## Backup
History tab → Export JSON Backup (lahat). Library tab → Export Library (para sa ibang phone).
